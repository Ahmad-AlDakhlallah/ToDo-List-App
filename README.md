# React Todo App

A simple and responsive Todo application built with React as part of my journey in learning and practicing React development.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and clean user interface
* Responsive design

## Technologies

* React
* JavaScript
* CSS
* Vite

[View Live Demo](https://to-do-list-ahmad.netlify.app)

## Purpose

This project was created to practice React fundamentals, component-based development, state management, and user interactions.
